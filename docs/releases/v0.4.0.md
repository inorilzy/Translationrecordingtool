## v0.4.0：新增 macOS 版

这一版开始支持 macOS（Apple Silicon，M 系列芯片），截图 OCR、划词翻译和离线词典都可以用。Windows 版功能和快捷键不变。

### 下载

| 文件 | 适用于 |
|---|---|
| `translation-tool_0.4.0_x64-setup.exe` | Windows（推荐，普通安装） |
| `translation-tool_0.4.0_x64_en-US.msi` | Windows（适合批量部署） |
| `translation-tool_0.4.0_aarch64.dmg` | macOS，打开后把应用拖进“应用程序” |
| `translation-tool_0.4.0_aarch64-portable.zip` | macOS 便携版，解压后直接运行，不用安装 |
| `SHA256SUMS-v0.4.0.txt` | 以上安装包的 SHA-256 校验值 |

校验方法：macOS 运行 `shasum -a 256 -c SHA256SUMS-v0.4.0.txt`；Windows 在 PowerShell 运行 `Get-FileHash <文件名> -Algorithm SHA256`，与文件中的值对比。

### 新功能

- **macOS 原生版本**：内置 PP-OCRv6 OCR 模型、ONNX Runtime 和离线词典，安装后不用另外下载。
- **macOS 划词翻译**：通过系统“辅助功能”直接读取选中的文字。
- **macOS 截图 OCR**：支持 Retina 屏幕，截图框选和翻译弹窗的位置都按实际显示比例计算。
- **macOS 默认快捷键**：
  - 划词翻译：`Option + Command + T`
  - 截图 OCR：`Option + Command + O`

  不使用 `Command + Q`，避免和系统“退出应用”冲突。可以在设置里修改。
- **剪贴板回退**：开启“选区读取失败时，自动复制并翻译”后，macOS 上会自动按 `Command + C`。

### 修复

- 修复打包后可能找不到 OCR 模型、导致截图 OCR 报“未找到模型”的问题。
- macOS 缺少屏幕录制权限时，会直接打开对应的系统设置页，并在 Finder 里定位应用，不再只给一段文字提示。

### macOS 首次使用

这个版本没有 Apple 开发者签名和公证，第一次使用需要多做几步：

1. **打开应用**：如果提示“无法验证开发者”，在 Finder 里右键应用 →“打开”→ 再点“打开”。
2. **截图 OCR 权限**：打开“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”，点列表下方的“+”，选“应用程序”里的 translation-tool，打开开关后退出并重新打开应用。
3. **划词翻译权限**：在“系统设置 → 隐私与安全性 → 辅助功能”里，用同样的方法添加 translation-tool。

> macOS 不会自动把这个应用放进权限列表，需要手动点“+”添加。更新到新版本后，旧的授权可能失效：在列表里删掉旧的 translation-tool，再重新添加。

### 翻译服务

默认是有道翻译，需要填写自己的应用 ID 和密钥。没有 Key 的话，可以在设置 → 翻译服务里选 **Google 翻译（免费）** 或 **微软翻译（免费）**，不用配置就能用。

### 已知限制

- macOS 版只支持 Apple Silicon（M1 及以后），暂不支持 Intel 芯片的 Mac。
- 暂不提供 Linux 版。
- 部分应用（游戏、自绘界面、某些 PDF 阅读器）读不到选中的文字，可以改用截图 OCR，或手动复制后用剪贴板翻译。
- Windows 和 macOS 的设置、历史记录分别保存，不会互相同步。

### 开发者说明

- **自动发布**：推送 `v*` 格式的 tag 后，GitHub Actions（`.github/workflows/release.yml`）会在 Windows 和 macOS 上并行打包，生成 `SHA256SUMS` 校验文件，并把安装包一起上传到同名 Release。Release 说明取自 `docs/releases/<tag>.md`。
- **跨平台准备脚本**：
  - `npm run ocr:models`：下载 PP-OCRv6 small 模型，固定上游 revision 并校验 SHA-256。
  - `npm run ocr:ort`：下载 ONNX Runtime 1.20.1（Windows x64 DLL / macOS arm64 dylib），校验下载包 SHA-256。

  原有的 PowerShell 脚本（`ocr:models:win`、`ocr:ort:win`）仍可在 Windows 上使用。
- **本地打包**：
  - Windows：`npm run tauri:build:ocr:native`（PowerShell 准备脚本）或 `npm run tauri:build:ocr:win`（Node 准备脚本，CI 使用）。
  - macOS：`npm run tauri:build:ocr:mac`，生成 `.app`、`.dmg` 和便携 `.zip`；DMG 用 `hdiutil` 生成，不依赖 Finder 自动化。
- **更新说明**：修改 `docs/releases/*.md` 并推送到 `main` 后，`.github/workflows/release-notes.yml` 会同步更新对应 Release 的说明，并在缺少时补上 `SHA256SUMS` 文件。
